# Ruize Gong — Academic Portfolio

Source for [ruizegong.github.io](https://ruizegong.github.io), an English academic portfolio focused on physical oceanography, climate dynamics, and scientific computing.

## Public content policy

This repository contains only public-safe research summaries. Unpublished manuscript text, figures, data, numerical results, and analysis materials are intentionally excluded.

## Built with

Semantic HTML, responsive CSS, and a small progressive-enhancement script. No build step is required.
